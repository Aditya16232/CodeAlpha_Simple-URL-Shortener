This a Simple URL Shortner Project.

1. Title + badge-less one-liner — "Simple URL Shortener" + short description
2. Features — shorten URLs, unique 6-char codes, 302 redirect, SQLite persistence, minimal web UI, 404 page
3. Tech stack — Flask, SQLite, HTML/CSS/JS
4. Quick start — exact commands for Windows/macOS/Linux (venv, pip install -r requirements.txt, python app.py)
5. Usage — browser UI flow + curl example for the API
6. API reference — POST /shorten (request/response JSON, error codes) and GET /<short_code> (302/404)
